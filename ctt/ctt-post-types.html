Post Types
Each post type gets its own accent color, applied via the Template dropdown in the WordPress editor. Reviews stay anchored to the homepage look; Playlists and Essays shift hue to signal "you're in a different section."
Reviews (Default Single Posts template)
Terracotta / warm brown — the site's default identity, same family as the homepage.
Hero overlay: rgba(35,22,16,0.86)
Sidebar tint: #f2ece2
Accent: #b5623a · Accent Light: #f0c8a0
Playlists (Playlist Posts template)
Dusty teal — the complement to terracotta, reads as "mixtape energy."
Hero overlay: rgba(28,42,39,0.74)
Sidebar tint: #e3ece9
Accent: #4a7a6f · Accent Light: #a8d4c8
Essays (Essay Posts template)
Dusty plum / wine — softer, more contemplative, for prose-heavy posts.
Hero overlay: rgba(36,26,33,0.74)
Sidebar tint: #ece3e6
Accent: #6b3f52 · Accent Light: #d9b8c9
Status Note
Hero overlay and sidebar tint are confirmed live in Additional CSS for both templates. The deep accent colors (headings, link hover, hairline rule, tag pill text) shown above were proposed as a "mini-styles" system but haven't been built into Additional CSS yet — flag this if you want them implemented.
